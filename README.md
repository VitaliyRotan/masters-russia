# Мастера России — версия V6

Статический сайт для GitHub Pages. Загрузите содержимое этой папки (не саму папку) в корень репозитория `masters-russia`. Стартовая страница — `index.html`.

Страницы: `index.html` — главная; `concept.html` — идея; `antonov.html`, `strusovsky.html`, `rotan.html` — персональный опыт; `production.html` — производство; `investment.html` — инвестиционное предложение первого этапа.

Финансовые условия возврата, права сторон, договорные механизмы и внутренние расчёты не публикуются. Резюме в виде документов в сайт не вложены.
