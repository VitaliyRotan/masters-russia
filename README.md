# Мастера России — сайт V4

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Все страницы используют относительные ссылки и готовы для статического размещения.
4. Дополнения команды: страницы Руслана Сахно, Светланы Сердюковой и Натальи Миклуш (после получения фотографий и проверенных сведений).
5. Страница `production.html` содержит опыт режиссёров и место для материалов нового производства.
6. Исходные PDF и DOCX резюме не включены. Биографии размещены прямо в HTML.
7. Дизайн: графит, серебро, бронза.
8. Контакт в публикации: Виталий Ротань, номер из предоставленного предложения.

Это презентационная версия, а не инвестиционный меморандум. Финансовые и договорные модели на сайте не раскрываются.
